# 투표 데이터

사이트는 두 곳의 투표를 합쳐서 보여줍니다.

| 위치 | 용도 | 배포 |
|---|---|---|
| `main` 브랜치 `data/polls.json` | 사이트와 함께 배포되는 기본 투표 | Vercel 배포됨 |
| `feed` 브랜치 `data/polls.json` | 자동 수집으로 계속 쌓이는 투표 | **배포 안 됨**. 사이트가 GitHub raw 주소에서 10분마다 직접 읽음 |

자동 수집 작업은 **feed 브랜치에만** 씁니다. Vercel 배포 횟수를 쓰지 않으므로 주말에도 그대로 돌아갑니다.

**예약 공개**: `at`이 아직 오지 않은 투표는 사이트에 보이지 않다가 그 시각에 자동으로 공개됩니다. 공개 간격은 **5분**입니다.

## 형식

```json
{
  "id": "f2611121405",
  "at": "2026-11-12T14:05:00+09:00",
  "cat": "연예",
  "sub": "아이돌·K팝",
  "type": "vs",
  "q": "질문 (40자 이내)",
  "o": ["보기 1", "보기 2"],
  "desc": "배경 설명 2~4문장. 기사·게시글 문장을 옮기지 않고 직접 쓴 문장.",
  "src": [{ "title": "출처 · 직접 쓴 짧은 제목", "url": "https://..." }]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | O | feed는 `f` + 공개 시각 `YYMMDDHHmm`. 예: `f2611121405`. 중복 금지 |
| `at` | O | 공개 시각. 5분 단위(:00, :05 … :55), ISO 8601, 한국 시간(+09:00) |
| `cat` | O | 대분류 값(아래 표의 `cat`) |
| `sub` | O | 소분류(아래 표) |
| `type` | O | `vs`(보기 2개) 또는 `multi`(보기 3~4개) |
| `q` | O | 질문, 40자 이내 |
| `o` | O | 보기 배열, 각 20자 이내 |
| `desc` | 권장 | 배경 설명 2~4문장 |
| `src` | 권장 | 참고 링크 1~2개 |
| `link` | X | 카드에 붙일 주소 1개. 유튜브 주소면 카드 안에서 재생되고(예고편·티저), 기사 주소면 카드 아래 "원문" 링크로 붙음. 영화 예고편은 배급사·공식 채널 영상만 |
| `v` | X | 득표 수. 비워 두면 0으로 시작 |

## 카테고리 (대분류 → 소분류)

| cat | 화면 이름 | 소분류 | 자동 수집 비율 |
|---|---|---|---|
| 연예 | 연예 | 아이돌·K팝 · 배우·드라마 · 예능·방송 · 영화 · 유튜버·인플루언서 | 28% |
| 사회 | 사회 | 직장·노동 · 교육·입시 · 생활·소비 · 교통·안전 · 환경·날씨 | 20% |
| 경제 | 경제 | 주식 · 부동산 · 금리·환율 · 코인 · 재테크·소비 | 16% |
| 라이프 | 라이프 | 연애·결혼 · 육아·가족 · 음식·맛집 · 여행·여가 · 건강·운동 | 12% |
| 스포츠 | 스포츠 | 야구 · 축구 · 농구·배구 · 골프·기타 · e스포츠 | 8% |
| IT·게임 | IT·게임 | AI·테크 · 스마트폰 · 게임 | 6% |
| 패션·쇼핑 | 패션·쇼핑 | 패션 · 뷰티 · 물건·가전 | 4% |
| 밸런스 | 밸런스 | 밸런스게임 · 취향 | 4% |
| 정치 | 정치·정책 | 제도 · 예산·세금 · 외교·국제 | 2% |
| 사연 | 사연·고민 | 연애 · 가족 · 직장 · 친구·인간관계 · 돈 | 자동 수집 안 함(사용자 글) |
| 그림·재능 | 그림·재능 | 아이 그림 · 작품·사진 | 자동 수집 안 함(사용자 글) |

같은 대분류가 연달아 공개되지 않게 섞습니다.

## 이슈를 찾는 곳

공개된 순위·목록에서 **주제(키워드)만** 가져오고, 글이나 기사 문장은 옮기지 않습니다.

- 실시간 검색 흐름: Google 트렌드 한국 급상승(RSS), 시그널 실시간 검색어 등 공개 순위
- 뉴스: 네이버·다음 많이 본 뉴스, 연예·스포츠 랭킹
- 커뮤니티: 네이트판 랭킹, 더쿠 HOT 등 공개 게시판의 **제목 흐름**만
- 영상·SNS: 유튜브 인기 급상승, 인스타그램·스레드·X에서 화제인 주제는 그것을 다룬 **기사**를 근거로 사용
- 네이버 카페·인스타그램·스레드처럼 로그인이 필요한 곳은 직접 수집하지 않는다

## 작성 규칙

- 실명 연예인의 열애·사생활·논란을 직접 묻지 않는다. 현상이나 제도로 바꿔 묻는다.
- 일반인이 등장하는 사건, 커뮤니티 사연을 그대로 옮기지 않는다. 주제를 일반화한다.
- 정치는 제도·정책 질문만. 정당·후보·정치인 이름 금지. 선거 기간에는 정치 투표를 올리지 않는다.
- 경제는 특정 종목·아파트 단지 이름 금지. "지금 팔 때일까?"처럼 시장 심리를 묻는 건 괜찮지만 답을 정해 주는 투자 권유 표현은 쓰지 않는다.
- 보기는 양쪽을 같은 무게와 말투로 쓴다. 한쪽을 비하하는 표현 금지.
- 사고·참사·범죄 피해 같은 비극적 사건은 투표 소재로 쓰지 않는다.
- 최근 3일 안에 올린 투표와 같은 주제는 다시 올리지 않는다.
- feed 파일은 최근 600개까지만 유지하고 오래된 것부터 지운다.
