# 매일 투표 데이터 (`data/polls.json`)

사이트는 열릴 때 이 파일을 읽어 기본 예시 투표와 합쳐 보여줍니다.

**예약 공개**: `at`이 아직 오지 않은 투표는 사이트에 보이지 않다가, 그 시각이 되면 자동으로 공개됩니다. 투표는 **매시 정각에 하나씩** 공개되도록 `at`을 한 시간 간격으로 잡습니다. 평일 아침 예약 작업이 이 대기열이 비지 않게 채웁니다.

## 형식

배열 하나에 투표 객체를 담습니다. 새 투표는 배열 맨 뒤에 붙입니다.

```json
{
  "id": "d261112-07",
  "at": "2026-11-12T07:00:00+09:00",
  "cat": "사회",
  "type": "vs",
  "q": "질문 (40자 이내)",
  "o": ["보기 1", "보기 2"],
  "desc": "배경 설명 2~4문장. 기사 문장을 옮기지 않고 직접 쓴 문장.",
  "src": [{ "title": "언론사 · 기사 제목 요약", "url": "https://..." }]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | O | `d` + 공개 날짜(YYMMDD) + `-` + 공개 시(00~23). 예: `d261112-07`. 중복 금지 |
| `at` | O | 공개 시각, 정각, ISO 8601, 한국 시간(+09:00). 마지막 예약 시각 + 1시간씩 |
| `cat` | O | `연예` `드라마·예능` `사회` `경제` `스포츠` `정치` `밸런스` 중 하나 |
| `type` | O | `vs`(보기 2개) 또는 `multi`(보기 3~4개) |
| `q` | O | 질문, 40자 이내 |
| `o` | O | 보기 배열, 각 20자 이내 |
| `desc` | 권장 | 배경 설명 2~4문장 |
| `src` | 권장 | 참고 링크 1~2개 |
| `v` | X | 득표 수. 비워 두면 0으로 시작 |
| `closed` | X | `true`면 마감. 발행 30일이 지나면 사이트가 자동으로 마감 처리 |

## 구성 비율

연예 약 26% · 사회 24% · 경제(부동산·주식) 20% · 드라마·예능 10% · 스포츠 10% · 정치 4% · 밸런스 6%. 같은 카테고리가 연달아 공개되지 않게 섞습니다.

## 대기열 규칙

- 월~목: 아직 공개되지 않은 투표가 30개 미만이면 30개가 되도록 채운다.
- 금: 다음 월요일 09:00까지 공개할 분량 + 6개가 되도록 채운다(주말에는 배포하지 않음).
- 날짜가 지나면 의미가 없어지는 주제(기념일, 경기 일정 등)는 공개 시각이 그 날짜 안에 들어가게 배치한다.

## 작성 규칙

- 실명 연예인의 열애·사생활·논란을 직접 묻지 않는다. 현상이나 제도로 바꿔 묻는다.
- 정치는 제도·정책 질문만. 정당·후보·정치인 이름 금지. 선거 기간에는 정치 투표를 올리지 않는다.
- 경제는 특정 종목·아파트 단지 이름 금지. "지금 팔 때일까?"처럼 시장 심리를 묻는 건 괜찮지만, 답을 정해 주는 투자 권유 표현은 쓰지 않는다.
- 보기는 양쪽을 같은 무게와 말투로 쓴다. 한쪽을 비하하는 표현 금지.
- 기사 본문을 옮기지 않는다. 설명은 직접 쓴 문장, 원문은 `src` 링크로만.
- 사고·참사·범죄 피해 같은 비극적 사건은 투표 소재로 쓰지 않는다.
- 파일은 최근 300개까지만 유지하고, 오래된 것부터 지운다.
