## 2. 참여 수와 시험 참여(DEMO)

**결정**: 정식 오픈 전까지는 시연을 위해 시험 참여를 보여 준다. 오픈 때 끈다.

- 대상: 실제 투표 id(`f`+10자리 피드, `d…` 기본 데이터, `u…` 사용자 투표). 릴레이·복수 선택·예시 투표·마감 투표는 제외.
- 흐름: 1분 안 1~10명 → 5~15분에 100명 안팎 → 이후 로그 곡선으로 완만히(하루 200~300명대).
- 실제처럼 불규칙하게: 15초 칸마다 잠잠함(약 28%)·보통·몰림(약 12%)이 섞이고, 칸마다 보기 비율이 조금씩 흔들림. 투표마다 시작 시점·속도가 다름.
- 투표 id와 시각으로 계산하는 결정적 값이라 누가 봐도 같은 숫자(시연 때 기기 여러 대로 열어도 일치).
- **서버에 저장하지 않는다**: 화면에서 `p._dv`로만 더함. Supabase `ny_votes`, 저장된 내 투표(`saveMine`)에는 들어가지 않음.
- 끄기: `DEMO_VOTES=off`(서버 `/api/config`의 `demo:false`) 또는 주소 `?demo=0`.
- 코드: `index.html`의 `var DEMO=(function(){…})()`.
- 사이트에는 BETA 표시를 둔다(마우스 올리면 "참여 수에는 시험용 예시 참여가 포함").

**같이 정한 것**
- 참여 0명이면 "0명 참여" 대신 "첫 투표자가 되어 보세요".
- 시안 초기에 넣은 "8초마다 아무 투표에나 표 더하기" 시뮬레이션은 예시 투표(실제 id가 아닌 것)에만 적용.
- **AI 예측 패널**(실제 결과와 따로 'AI 패널 100명' 표시)은 만들었다가 사용자 요청으로 뺐다.

## 3. AI 사용 원칙

- **사람인 척하는 AI 댓글은 넣지 않는다.** (닉네임·말투·경험담으로 사람처럼 보이게 하는 것)

- 자동 수집 작업이 투표를 쓰는 것은 괜찮다(운영자 콘텐츠). 다만 작성 규칙(아래 5장)을 지킨다.

## 4. 피드(메인) 정책

**추천(기본 첫 화면)**
- 점수 = 인기 + 새로움 + 무작위 + 형식 가산점 + 관심사 − 이미 투표 − 예시.
- 같은 카테고리가 연달아 나오지 않게 섞음(최근 4개 중 같은 카테고리 최대 2개).
- **형식 리듬**: OX → 사진 → OX → 영상 → … 반복(영상 없으면 사진, 사진 없으면 영상). 긴 사연·릴레이·보기 많은 객관식은 뒤로.
- 방문할 때마다 순서가 바뀌고, 보는 동안은 유지. "추천" 탭을 다시 누르면 새로 섞고 맨 위로.
- **이미 투표한 투표는 추천에서 숨김.** 투표 직후에는 그 자리에 남겨 결과를 보게 하고, 다음 방문부터 뺀다. 다 보면 "투표한 N개는 내 투표에 있어요 · 최신 순으로 전체 보기" 안내.
- **최신 / 카테고리 / 검색**에서는 투표한 것도 모두 보인다.
- 방금 올린 내 투표는 메인 맨 위에 "방금 올린 투표"로 고정 표시.
- 사진·영상 비율을 높이려면 자동 수집 투표에 공식 유튜브 영상(`link`)을 붙이는 방향(사용자 결정 대기).

**내 투표 (메뉴 ≡ → 내 투표)**
- 탭: 투표한 것 / 다수 편 / 소수 편 / 내가 만든 것. 내 선택, 현재 비율, 다수·소수 편, 투표 시각.
- 비로그인: 이 브라우저 기록(`neaniyo-voted`, `neaniyo-vlog`). 로그인: 서버 `ny_votes` 합쳐서 다른 기기 것도 보임.

## 5. 투표 만들기 정책

- **토스식 순차 노출**: 처음엔 "무엇을 물어볼까요?" 한 칸 → 제목 2자 이상이면 보기·[내용][사진][링크·유튜브]·설정·하단 고정 올리기가 펼쳐짐. 필수는 **제목 하나**.
- 순서는 제목 → 보기 → (선택) 내용·사진·링크. 내용은 선택이라 단계로 강제하지 않음.
- 하단 고정 바: "✨ 이렇게 올라가요 OX" + 카테고리 칩(누르면 카테고리 선택).
- **답 형식 추천**(제목 말투): 사귈까→사귄다, 살까→산다, 볼까→본다, 갈까/등반/여행→간다, 어때→좋다/별로다, 할까→한다, 맞을까/될까→O/X, 그 외 찬성/반대. **"A vs B", "A 대 B", "A or B"** 면 A/B. 보기를 비우면 추천 보기로 올라감.
- 칩을 누르면 보기 2개 채우고 3·4 칸 숨김, 같은 칩 다시 누르면 원래대로. 릴레이 질문마다도 동일.
- 사진: 최대 10장. 2장 이상이면 "사진 중에서 고르기"(6장까지) / "사진 보여주고 묻기"(넘겨 보는 갤러리 + OX·보기).
- 링크: 유튜브는 카드 안에서 재생, 기사는 "원문" 링크.
- 형식은 고르지 않고 내용으로 자동 판단(사연 글 → 사연 판정, 사진 → 사진 투표, 보기 3개 이상 → 객관식).
- 카테고리는 제목 키워드로 자동 선택(직접 바꾸면 그 값). 정해지기 전에는 "카테고리"로 표시.
- 내 투표 **수정·삭제**: 카드의 수정/삭제(삭제는 두 번 눌러야). 수정해도 주소 유지, 보기를 바꾸면 표 초기화.
- **공개 투표는 바로 공개**(사후 관리). 서버가 제목·보기·내용을 운영 규칙(`data/moderation.json`)으로 검사: 금지 → 거절(422), 검토 → 승인 대기. `POLL_REVIEW=pre`면 예전처럼 모든 공개 투표를 사전 승인.
- 링크 공유·비밀방은 올린 뒤 주소 복사 화면을 보여 줌.

## 6. 콘텐츠·법적 규칙 (자동 수집 포함)

`data/README.md`의 작성 규칙을 따른다. 요점:
- 실명 연예인의 열애·사생활·논란을 직접 묻지 않는다.
- 정치는 제도·정책만, 정당·후보·정치인 이름 금지. 선거 관련 결과는 여론조사로 공표·보도할 수 없다는 문구(리포트에 자동).
- 경제는 특정 종목·아파트 단지 이름 금지, 투자 권유 표현 금지. 경제 카드에 "투자 판단 근거 아님".
- 사고·참사·범죄 피해는 소재로 쓰지 않는다.
- 뉴스·인스타 이미지를 가져다 쓰지 않는다(저작권). 유튜브는 임베드로만.
- 결과는 "참여자 기준, 표본 조사 아님".

## 7. 공유·임베드

- 휴대폰 **공유** 버튼: 기기 공유창으로 **링크만** 보냄(임베드 코드가 카톡으로 가던 문제 해결). 휴대폰에서는 임베드 버튼 숨김.

- 카톡·SNS 미리보기: 대표 이미지 `assets/og.jpg`(1200×630) + og 태그. **투표마다 다른 미리보기 이미지는 미구현**(Vercel 함수로 서버 렌더 필요, 사용자 결정 대기).

## 9. 화면(UI) 결정 기록

**유지**
- 모바일 앱형: 상단 로고·검색·계정·메뉴(≡), 하단 탭(투표·랭킹·⊕만들기·프리미엄·분석).
- 아래로 스크롤하면 헤더·하단 탭 숨김, 위로 올리면 보임.
- 상단 카테고리 탭: **글자만**(아이콘 없음), 선택 밑줄은 카테고리 색.
- 카드 분류 표시에는 카테고리 컬러 동그라미 아이콘(Lucide). 색: 추천 금색, 최신 청록, 연예 핑크, 사회 파랑, 경제 초록, 라이프 커피 갈색, 사연 로즈, 패션 보라, 스포츠 주황, IT 인디고, 그림 틸, 정치 회청, 밸런스 라임.
- 유튜브 카드: 화면에 보이면 소리 끈 채 자동재생, 벗어나면 정지. 평소엔 작은 소리 버튼만, 탭하면 자막·유튜브 버튼 3초 노출.
- 카드 하단(모바일): 동그라미 아이콘 버튼(통계·공유).
- 실시간 인기 투표(모바일): 한 줄 롤링, ∨로 10위 목록 펼치기.
- 메인 "새 투표가 5분마다 올라와요" 안내는 **제거**(예약 공개는 동작).
- 아이콘은 Lucide.

**해 봤다가 되돌린 것 (다시 넣지 말 것, 요청 시에만)**
- 스크롤하면 "+ 투표 만들기"로 펼쳐지는 떠 있는 버튼 → 복잡해 보여서 제거.
- 상단 카테고리 탭 아이콘 → 제거.
- AI 예측 패널 → 제거.

## 10. 작업 방식

- 작업이 끝나면 **바로 main에 push**(평일·주말 상관없이). Vercel이 자동 배포.
- 커밋 작성자: `handgoldking1234 <handgoldking1234@users.noreply.github.com>`.
- push 전에 `git fetch` → `rebase`(다른 세션이 동시에 고치는 경우가 있었음). 같은 기능을 두 세션에서 동시에 고치지 않기.
- 퍼블리싱 요청은 순수 마크업 + 간단한 스크립트 원칙. 서버 작업은 `api/*.js`(의존성 없음).
- 응답은 한국어, 무엇이 바뀌었는지 짧고 순서대로.
- 테스트: Playwright(휴대폰 Pixel 7 크기)로 화면 확인 후 올림.
